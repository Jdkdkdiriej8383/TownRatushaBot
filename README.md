# 🏛 TownBot — Ролевой Telegram-бот Города (Minecraft RP)

Высоконагруженный, строго типизированный асинхронный Telegram-бот на базе **aiogram 3.x**, **PostgreSQL** (SQLAlchemy 2.0 Async), **FastAPI** и **APScheduler**. 

Проект разработан для полной замены устаревших чат-менеджеров (типа «Ирис»), обеспечивает неукоснительное соблюдение Городского Свода Законов, внедряет конфигурируемую систему **«Регуляторов прав и лимитов»** с защитой субординации и предоставляет **Cross-Bot API (Intercom)** для бесшовной интеграции со вторым ботом опросов.

---

## ⚖️ 1. Терминология и Иерархия должностей

> **Критическое правило регламента:**  
> В системе категорически **запрещены** слова «Ранг» (используется только **«Должность»**) и «Модератор» (используется только **«Блюститель»**).

### Иерархия доступа (Уровни 0–5):
- **0: Гражданин** — базовые права жителя, доступ к РП-действиям, паспорту, казне, подаче судебных исков и участию в голосованиях.
- **1: Помощник** *(младший блюститель)* — первичный надзор, предупреждения, чистка спама, право на мут до 2 часов (7 200 сек).
- **2: Блюститель чата** — надзор за чатом Telegram, муты до 24 часов (86 400 сек), взыскание штрафов строго по статьям **Раздела II**.
- **3: Старший блюститель** — баны (изгнание) сроком до 7 дней, игровые штрафы до 200 000 валюты, созыв суда присяжных.
- **4: Администрация** — полный доступ к надзору, оперативное редактирование статей Свода Законов (`/закон_ред`), перманентное изгнание.
- **5: Старшая администрация** — полный доступ, назначение и снятие любых должностей, настройка регуляторов и инициация общегородских референдумов.

**Спец-статус «Враг города» (`is_enemy = True`):**  
Применяется по ст. 1.4 за государственную измену, читы или теракт. Лишает жителя абсолютно всех гражданских прав, возможности голосовать и блокирует в городском реестре.

## 🛡 2. Система «Регуляторов» (Configurable Regulators & Limits)

Контроль полномочий реализован на уровне базы данных (`regulators`) и сервисного слоя (`RegulatorService`):

1. **Защита субординации:**  
   Блюститель имеет право применять санкции (`/наказать`, `/штраф`, `/должность`, арест) **ТОЛЬКО** к лицам с должностью **СТРОГО НИЖЕ** своей. Попытка наказать равного или старшего пресекается системной ошибкой `SubordinationViolationError`.
2. **Лимиты полномочий в БД:**
   - `max_mute_time`: потолок времени мута в секундах для конкретной должности.
   - `max_fine_amount`: максимальная сумма выписываемого штрафа.
   - `can_ban`: право на изгнание жителя.
   - `can_edit_laws`: право изменять текст статей закона (только уровни 4 и 5).
   - `can_appoint_level`: максимальный уровень должности, который блюститель уполномочен присваивать.
3. **Защитные регуляторы чата (`ChatRegulatorMiddleware`):**  
   Администрация на лету может включать/отключать фильтры в чате:
   - **Анти-капс:** автоматическое удаление сообщений, содержащих более 70% заглавных букв при длине более 6 символов (ст. 2.2).
   - **Медиа-спам:** авто-удаление и ограничение речи нарушителя при отправке более 3 ГС/кружков/стикеров подряд за 15 секунд (ст. 2.3).
   - **Анти-ссылки:** пресечение публикаций сторонних ссылок и рекламы без одобрения властей (ст. 2.4).

## 📡 3. Cross-Bot API & Интеграция с ботом опросов (Intercom)

Внутри процесса TownBot в едином `asyncio event loop` работает высокоскоростной сервер **FastAPI**, защищенный взаимной авторизацией по токену (`Bearer` / `X-Intercom-Token`).

### Реализованные сценарии взаимодействия:
1. **Общегородской референдум:**  
   Старшая администрация через `/референдум [статья] [текст]` инициирует поправку в закон. TownBot через HTTP-клиент передает команду боту опросов на создание официального голосования.
2. **Проверка права голоса (`GET /api/v1/users/{telegram_id}/voting-status`):**  
   Перед учетом голоса бот опросов проверяет статус жителя: голосовать могут **только** жители с должностью «Гражданин» и выше. «Враги города» категорически поражены в правах.
3. **Суд присяжных заседателей (`/присяжные @юзер [статья] [обвинение]`):**  
   Вынесение спорных дел на открытый суд граждан.
4. **Синхронизация результатов (`POST /api/v1/referendum/result`):**  
   По завершении голосования бот опросов отправляет webhook с итогами:
   - При одобрении референдума TownBot **автоматически применяет новую редакцию закона в PostgreSQL** и отправляет вестник в чат города.
   - При признании вины судом присяжных нарушитель объявляется в розыск.

## 🏛 4. Городской Свод Законов и Судебная система

Законы хранятся в PostgreSQL в таблице `laws` и разделены на 4 раздела:
- **Раздел I.** Общие положения (1.1 - 1.4)
- **Раздел II.** Чат Telegram (2.1 - 2.12)
- **Раздел III.** Внутриигровые законы (Безопасность 3.1-3.12, Стройка 3.13-3.20, Экономика 3.21-3.28)
- **Раздел IV.** Служба и работа (4.1 - 4.4)

### Судебные команды:
- `/закон [номер]` — карточка статьи с регламентом наказания.
- `/законы` — полный реестр всех статей города.
- `/закон_ред [номер] [новый_текст]` — редактирование закона (уровни 4-5).
- `/наказать @юзер [номер_статьи]` — проверка должности блюстителя, наложение санкции (мут/бан в Telegram API) и фиксация в протокол суда `punishments`.
- `/штраф @юзер [номер_статьи] [сумма] [причина]` — выписка официального тикета штрафа с **таймером на 48 часов** (по п. 3.12).
  - **Авто-удвоение:** фоновый планировщик каждые 60 секунд проверяет просроченные штрафы. Если прошло более 48 часов, сумма удваивается (х2), а житель автоматически объявляется в **общегородской розыск (`is_wanted = True`)**.
- `/досье @юзер` — полная выписка судимостей, открытых задолженностей и предупреждений.
- `/оплатить [id_штрафа]` — погашение штрафа гражданином и снятие статуса розыска.

## 🪪 5. Паспорт и Ролевые взаимодействия (РП)

- `/паспорт` — электронный паспорт жителя: Minecraft-ник, Должность, статус отпуска, история штрафов и статус розыска.
- `/ник [Minecraft-ник]` — привязка игрового никнейма.
- `/отпуск [1-30]` — оформление отпуска гражданина (ст. 3.25), защищающего постройки от сноса за неактивность.
- `/должность @юзер [0-5]` — изменение должности с контролем субординации.

### RP-действия (работают текстом и реплаем):
- `отдать честь [@юзер]` — уставное воинское приветствие с субординацией.
- `арестовать [@юзер]` — задержание нарушителя или лица в розыске блюстителем.
- `досмотреть [@юзер]` — обыск личных вещей и карманов.
- `пожать руку [@юзер]` — жест взаимного уважения и равенства.
- `выдать повестку [@юзер]` — официальное предписание явиться в Городской Суд.

## 🚀 Быстрый запуск

### 1. Локальный запуск
```bash
# Клонирование и переход в директорию
cd townbot

# Создание и активация виртуального окружения
python -m venv .venv
source .venv/bin/activate  # На Windows: .\.venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt

# Настройка переменных окружения
cp .env.example .env
# Отредактируйте BOT_TOKEN, DATABASE_URL и INTERCOM_SECRET_TOKEN в .env

# Инициализация базы данных и сидинг законов
python -m db.seed

# Запуск TownBot + Cross-Bot API
python main.py
```

### 2. Запуск через Docker Compose
```bash
docker-compose up -d --build
```

### 3. Развертывание на Render.com (Бесплатный хост)
Проект полностью подготовлен к развертыванию на бесплатном тарифе **Render.com**:
- Поддерживается автоматический деплой в 1 клик через **Blueprint (`render.yaml`)**.
- Автоматическая адаптация системной переменной `$PORT` -> `API_PORT`.
- Встроенные эндпоинты Health Check (`/` и `/health`).
- Поддержка форматов `postgres://` и `postgresql://` от Render/Neon с автоконвертацией в `asyncpg`.
- Инструкция по удержанию бота в сети 24/7 (защита от засыпания).

Подробная пошаговая инструкция доступна в [RENDER_DEPLOY.md](RENDER_DEPLOY.md).

### 4. Запуск тестов
```bash
pytest -v
```
Все 18 тестов (юнит-тесты субординации, регуляторов, штрафов 48ч, законов, Cross-Bot API, health check, конфигурации и aiogram-хэндлеров) выполняются автоматически.
